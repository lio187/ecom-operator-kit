# Static Ad Matrix

Maakt veel duidelijke statics zonder willekeur.

- Input: angles, hooks, bewijs, productbeelden en brandregels.
- Werkwijze: combineert boodschap, layout, bewijs en CTA per testvariabele.
- Output: matrix met testbare static-advarianten.
- Gebruik: wanneer je snel meerdere heldere concepten wilt testen.
